# Rotas implementadas

## Auth

- `POST /auth/register`
- `POST /auth/login`
- `POST /auth/refresh`
- `POST /auth/logout`
- `GET /auth/me`

## Condominiums

- `GET /condominiums`
- `POST /condominiums`
- `PATCH /condominiums/:id`

## Users

- `GET /users`
- `POST /users`

## Expenses

- `GET /expenses`
- `POST /expenses`

## Invoices

- `GET /invoices?userId=&condominiumId=&status=`
- `POST /invoices`

## Notifications

- `POST /notifications/devices`
- `GET /notifications`
- `POST /notifications`
